CHƯƠNG 2. CÀI ĐẶT & KHỞI ĐỘNG

2.1. Cài đặt phần mềm

1
Tải file cài đặt Karate Tournament Manager Setup x.x.x.exe từ nhà cung cấp
2
Nhấp đúp vào file .exe để chạy trình cài đặt
3
Chọn thư mục cài đặt (mặc định: C:\Program Files\Karate Tournament Manager)
4
Nhấn Install và chờ quá trình hoàn tất (khoảng 1-2 phút)
5
Nhấn Finish — Phần mềm tạo shortcut trên Desktop
💡 Lưu ý: Nếu Windows Defender cảnh báo "Unknown Publisher", chọn "More info" → "Run anyway". Đây là cảnh báo thông thường với phần mềm chưa được ký số bởi Microsoft.

2.2. Khởi động phần mềm

  • Nhấp đúp biểu tượng Karate Tournament Manager trên Desktop, hoặc vào Start Menu
  • Màn hình Splash/License hiển thị trong vài giây rồi tự chuyển sang màn hình chọn vai trò
  • Lần đầu cài đặt: Phần mềm tự kích hoạt chế độ Dùng thử (Trial) — đầy đủ tính năng trong thời hạn giới hạn
⚠️ Tắt phần mềm đúng cách: Nhấn X để đóng hoặc dùng Alt+F4. Không tắt đột ngột bằng Task Manager để tránh mất dữ liệu đang xử lý.

CHƯƠNG 4. MÀN HÌNH CHỌN VAI TRÒ

4.1. Giới thiệu 3 vai trò

Khi mở phần mềm, màn hình chọn vai trò hiển thị 3 thẻ lớn. Nhấn vào thẻ tương ứng với chức năng bạn cần:

ThẻVai tròNên chọn khi
👨‍💼 AdminBan tổ chứcBạn quản lý giải đấu, cần bốc thăm, in PDF, xem thống kê
🏆 Huấn luyện viênHLV đội/CLBBạn nhận file .krt từ Admin và cần nhập danh sách VĐV
🎯 Thư kýThư ký trận đấuBạn nhận file .kmatch từ Admin và cần bấm điểm các trận

4.2. Chuyển đổi vai trò

  • Nhấn nút "← Quay lại" hoặc "Đổi vai trò" từ bất kỳ màn hình nào để quay về màn hình chọn vai trò
  • Một máy tính có thể dùng luân phiên cả 3 vai trò — dữ liệu mỗi vai trò được lưu riêng biệt
💡 Gợi ý: Trong một buổi tổ chức giải, người vận hành máy tính chính thường dùng vai trò Admin. HLV và Thư ký dùng các máy tính riêng hoặc nhận/gửi file qua USB/Zalo.

CHƯƠNG 5. HƯỚNG DẪN ADMIN — 👨‍💼 Ban tổ chức

Admin là vai trò trung tâm, có toàn quyền quản lý giải đấu. Admin tạo giải đấu, bốc thăm, xuất file cho HLV/Thư ký và tổng hợp kết quả cuối cùng.

5.1. Tạo giải đấu mới

1
Từ trang chủ Admin → nhấn nút "+ Tạo giải đấu mới"
2
Điền thông tin:
• Tên giải đấu (bắt buộc) — VD: "Vô địch Karate TP.HCM 2026"
• Ngày bắt đầu / Ngày kết thúc
• Địa điểm tổ chức
3
Nhấn "Tạo giải đấu" → Giải đấu mới xuất hiện trong danh sách trang chủ

5.2. Quản lý hạng mục thi đấu

Nhấn "Mở giải đấu →" để vào trang quản lý chi tiết.

Cách 1: Thêm hạng mục thủ công

1
Nhấn "➕ Thêm hạng mục" ở thanh công cụ trên cùng
2
Điền thông tin:
• Tên hạng mục — VD: "Kumite Nam -60kg Senior"
• Nội dung: Kumite (Đối kháng) hoặc Kata (Quyền)
• Giới tính: Nam / Nữ / Hỗn hợp
• Hạng cân (cho Kumite), Lứa tuổi
• Thể thức: Loại trực tiếp / Có vòng vớt
3
Nhấn "Thêm hạng mục"

Cách 2: Import hàng loạt từ Excel

1
Nhấn "📥 Tải mẫu Excel" để tải file mẫu hạng mục về máy
2
Mở file Excel mẫu → Điền danh sách hạng mục theo các cột có sẵn
3
Nhấn "📤 Import từ Excel" → Chọn file đã điền
4
Hệ thống thông báo số hạng mục đã import thành công

5.3. Quản lý Vận động viên (VĐV)

Nhấn "Quản lý →" ở hạng mục bất kỳ trên trang giải đấu để vào trang quản lý VĐV của hạng mục đó.

Thêm VĐV thủ công

1
Nhấn "+ Thêm VĐV"
2
Điền thông tin VĐV: Họ tên · Giới tính · Ngày sinh · Đơn vị/CLB · Cân nặng · Hạt giống (1-8 nếu có)
3
Tick "Thi đấu đồng đội" nếu đây là hạng mục đồng đội
4
Nhấn "Thêm VĐV"

Import VĐV từ nhiều CLB (khuyến nghị)

1
Từ thanh công cụ giải đấu → Nhấn "🏢 Import VĐV từ CLB"
2
Chọn một hoặc nhiều file Excel từ các HLV gửi về (giữ Ctrl để chọn nhiều file)
3
Hệ thống tự động ghép VĐV vào đúng hạng mục theo tên nội dung thi đấu
4
Xem kết quả preview: số VĐV khớp / không khớp → Nhấn "Chấp nhận import"

5.4. Bốc thăm tự động

⚠️ Yêu cầu: Hạng mục cần ít nhất 2 VĐV mới có thể bốc thăm. Hạng mục đồng đội cần ít nhất 2 CLB khác nhau.

Bốc thăm từng hạng mục

1
Vào trang hạng mục → Nhấn "🎲 Bốc thăm"
2
Xem thông tin xác nhận: số VĐV · số slots · số BYE · số hạt giống
3
Nhấn "🎲 Bốc thăm ngay"
4
Hiệu ứng đếm ngược 5 giây kèm xáo trộn tên VĐV → Tự động chuyển sang trang Sơ đồ thi đấu

Bốc thăm tất cả cùng lúc (Bulk Draw)

1
Từ trang giải đấu → Nhấn "🎲 Bốc thăm tất cả" (có badge hiển thị số hạng mục có thể bốc)
2
Chọn/bỏ chọn các hạng mục muốn bốc thăm → Nhấn "Bốc thăm các nội dung đã chọn"
3
Hệ thống báo kết quả: Thành công · Bỏ qua · Lỗi
✅ Thuật toán bốc thăm thông minh:
• Đặt hạt giống đúng vị trí (Seed 1 đầu trên, Seed 2 đầu dưới bảng)
• Phân bổ để VĐV cùng CLB không gặp nhau ở vòng 1
• Chia BYE đều hai nửa bảng đấu
⚠️ Bốc thăm lại: Nhấn "🔄 Bốc thăm lại" — Tất cả kết quả trận đấu cũ sẽ bị xóa. Hệ thống tự động tạo auto-backup trước khi xóa.

5.5. Xem Sơ đồ thi đấu (Bracket)

1
Sau khi bốc thăm → Nhấn "📊 Xem sơ đồ thi đấu"
2
Bracket hiển thị dạng cây nhánh: AKA 🔴 (đỏ) ở trên, AO 🔵 (xanh) ở dưới. Ô có chữ BYE là lượt trống.
3
Nhấn vào ô trận đấu bất kỳ → Mở Scoreboard bấm điểm trực tiếp

5.6. Xuất PDF

Nút bấmVị tríTác dụng
📄 Xuất PDFTrang sơ đồ thi đấuXuất sơ đồ 1 hạng mục thành file PDF
📄 Xuất tất cả PDFTrang giải đấuXuất toàn bộ hạng mục đã bốc thăm vào 1 file PDF
📄 Xuất kết quả PDFTrang Thống kêXuất bảng kết quả / huy chương thành PDF

5.7. Tạo và xuất file .krt cho HLV

File .krt là file cấu hình giải đấu gửi cho HLV để nhập danh sách VĐV trong thời hạn quy định.

1
Từ trang giải đấu → Nhấn "📤 Xuất (.krt)"
2
Thiết lập thời gian:
• Thời gian bắt đầu nhập: Mốc HLV được phép bắt đầu nhập VĐV
• Thời gian kết thúc (Deadline): HLV phải nộp xong trước mốc này
3
Kiểm tra danh sách nội dung thi đấu (tự động lấy từ hạng mục đã tạo)
4
Nhấn "📤 Xuất file .krt" → Chọn nơi lưu file
5
Gửi file .krt cho các HLV qua: USB · Email · Zalo · Google Drive

5.8. Tạo và xuất file .kmatch cho Thư ký

File .kmatch là file bấm điểm, phải xuất sau khi đã bốc thăm xong ít nhất 1 hạng mục.

1
Từ trang giải đấu → Nhấn "🎯 Xuất (.kmatch)"
2
Thiết lập:
• Cho phép nhập điểm ngay: Tick để Thư ký có thể bấm điểm ngay lập tức
• Thời gian bắt đầu/kết thúc: Khoảng thời gian cho phép bấm điểm
3
Nhấn "🎯 Xuất file .kmatch" → Gửi cho Thư ký

5.9. Import kết quả từ Thư ký

1
Nhận file kết quả từ Thư ký (định dạng JSON hoặc Excel)
2
Vào Trang Thống kê → Tab "Kết quả"
3
Nhấn "📥 Import kết quả" → Chọn file
4
Xem preview → Chọn chế độ:
• Gộp: Giữ cả dữ liệu cũ và mới
• Ghi đè: Thay thế hoàn toàn bằng dữ liệu từ Thư ký

5.10. Trang Thống kê

Nhấn nút "📊 Thống kê" của bất kỳ giải đấu nào để vào trang tổng hợp. Gồm 5 tab:

TabNội dung
📊 Tổng quanSố VĐV, CLB, hạng mục, ước tính huy chương cần trao

CHƯƠNG 6. HƯỚNG DẪN HUẤN LUYỆN VIÊN 🏆 HLV

HLV nhận file .krt từ Admin, nhập danh sách VĐV trong thời hạn quy định, rồi xuất file gửi lại cho Admin.

⚠️ Quan trọng: HLV chỉ có thể thêm/sửa/xóa VĐV trong khoảng thời gian Admin quy định. Ngoài thời hạn, chức năng chỉnh sửa bị khóa hoàn toàn. Liên hệ Admin nếu cần gia hạn thêm thời gian.

6.1. Mở file .krt

1
Mở phần mềm → Nhấn thẻ "🏆 Huấn luyện viên" ở màn hình chọn vai trò
2
Nhấn nút "📁 Mở file .krt"
3
Duyệt đến file .krt do Admin gửi → Nhấn Open
4
Màn hình hiển thị:
• Tên giải đấu
• Trạng thái thời gian: Chưa đến / Đang trong thời hạn / Đã hết hạn
• Đồng hồ đếm ngược đến deadline
• Danh sách nội dung thi đấu có thể đăng ký

6.2. Điền thông tin HLV và CLB

1
Điền Tên HLV vào ô tương ứng ở đầu trang
2
Điền Tên CLB / Đơn vị
3
Thêm Trưởng đoàn và HLV phụ (nếu có)
4
Thông tin được lưu tự động vào cơ sở dữ liệu — không cần nhấn Save

6.3. Thêm Vận động viên

Cách 1: Thêm thủ công từng VĐV

1
Nhấn "+ Thêm VĐV"
2
Điền thông tin VĐV:
• Họ tên (bắt buộc)
• Giới tính (bắt buộc)
• Ngày sinh · Cân nặng (kg)
• Nội dung thi đấu (bắt buộc) — chọn từ dropdown danh sách của giải
• Tick "Thi đấu đồng đội" nếu VĐV này thi nội dung đồng đội
3
Nhấn "Thêm" — VĐV xuất hiện trong danh sách

Cách 2: Import danh sách từ Excel

1
Nhấn "📥 Tải mẫu Excel" để tải file mẫu HLV về máy
2
Mở file Excel mẫu → Điền toàn bộ danh sách VĐV của CLB
3
Nhấn "📤 Import Excel" → Chọn file đã điền
4
Hệ thống tự động ghép VĐV vào đúng nội dung theo tên trong cột Nội dung thi đấu
⚠️ Lưu ý khi import: Tên nội dung thi đấu trong file Excel phải khớp hoặc gần khớp với tên Admin đã thiết lập trong file .krt. VD: "Kumite Nam" sẽ khớp với "Kumite Nam -60kg".

6.4. Chỉnh sửa và xóa VĐV

  • Nhấn ✏️ (Edit) bên cạnh tên VĐV để mở form chỉnh sửa
  • Nhấn 🗑️ (Delete) để xóa VĐV — hệ thống yêu cầu xác nhận
  • Cả 2 chức năng chỉ hoạt động khi đang trong thời hạn nhập

6.5. Xuất file gửi Admin

1
Cuộn xuống phần "📤 Xuất file gửi Admin" ở cuối trang
2
Chọn định dạng xuất:
• 📄 Xuất JSON — File dữ liệu thuần túy, chính xác nhất (khuyến nghị)
• 📊 Xuất Excel — Dễ xem và kiểm tra trên máy tính trước khi gửi
3
Chọn nơi lưu file → Gửi cho Admin qua: USB · Email · Zalo · Google Drive
✅ Mẹo cho HLV:
• Kiểm tra kỹ tên nội dung thi đấu — phải khớp với danh sách trong file .krt
• Nên gửi file JSON thay vì Excel để giảm khả năng lỗi định dạng
• Gửi file cho Admin trước deadline ít nhất 1 ngày để xử lý kịp thời

CHƯƠNG 8. BACKUP & ĐỒNG BỘ DỮ LIỆU

Tính năng Backup giúp sao lưu toàn bộ dữ liệu giải đấu và đồng bộ giữa nhiều máy quản lý khác nhau. Đây là tính năng quan trọng khi có nhiều Admin cùng quản lý một giải.

8.1. Mở Quản lý Backup

1
Từ trang chủ Admin → Nhấn nút "💾 Backup" hoặc biểu tượng đám mây
2
Cửa sổ "Quản lý Backup" mở ra, hiển thị: Số giải đấu · Dung lượng dữ liệu · Số bản auto-backup

8.2. Xuất Backup — Sao lưu dữ liệu

1
Nhấn thẻ "📤 Xuất Backup"
2
Nhập ghi chú để dễ phân biệt sau — VD: "Backup sau khi import VĐV CLB Hà Nội"
3
Nhấn "💾 Xuất file Backup (.kbackup)"
4
Chọn vị trí lưu → File .kbackup chứa toàn bộ dữ liệu tất cả giải đấu

8.3. Nhập Backup — Khôi phục dữ liệu

1
Nhấn thẻ "📥 Nhập Backup"
2
Chọn file .kbackup từ Admin khác hoặc từ bản backup cũ của mình
3
Hệ thống hiển thị bảng so sánh chi tiết:
• Số giải đấu · Hạng mục · VĐV · Đã bốc thăm — của máy hiện tại vs file backup
• Danh sách giải: Mới trong backup / Khác biệt / Chỉ có ở máy này / Giống nhau
4
Chọn chế độ khôi phục:
• "🔀 Gộp dữ liệu" — Giữ cả 2, giải trùng ID giữ bản có nhiều dữ liệu hơn (AN TOÀN)
• "🔄 Thay thế" — Xóa hết dữ liệu hiện tại, thay bằng backup (dữ liệu cũ tự auto-backup trước)

8.4. Tạo Checkpoint thủ công

1
Nhấn thẻ "📌 Tạo Checkpoint"
2
Hệ thống lưu trạng thái hiện tại vào danh sách Auto-backup với nhãn "Checkpoint thủ công"
3
Có thể khôi phục checkpoint này sau từ mục "🕐 Lịch sử Backup"
💡 Khi nào nên tạo Checkpoint: Trước khi bốc thăm · Trước khi import dữ liệu lớn · Trước khi thực hiện thay đổi quan trọng

8.5. Xem lịch sử & Khôi phục Auto-backup

1
Nhấn thẻ "🕐 Lịch sử Backup"
2
Danh sách bản auto-backup hiển thị: thời gian tạo · lý do tạo · dung lượng
3
Nhấn "Khôi phục" ở bản muốn phục hồi → Xác nhận → Dữ liệu hiện tại được auto-backup rồi khôi phục
💡 Quy trình đồng bộ nhiều Admin:
1. Admin chính Xuất Backup → gửi file .kbackup cho Admin phụ (Zalo/USB/Drive)
2. Admin phụ Nhập Backup → chọn Gộp dữ liệu → tiếp tục làm việc
3. Khi xong, Admin phụ Xuất Backup lại → gửi về cho Admin chính để cập nhật

CHƯƠNG 10. CÂU HỎI THƯỜNG GẶP (FAQ)

❓ Phần mềm có cần internet không?
Không. Phần mềm hoạt động 100% offline. Chỉ cần internet khi: kích hoạt license lần đầu, gửi yêu cầu hỗ trợ qua phần mềm, hoặc cập nhật phiên bản mới.
❓ Dữ liệu được lưu ở đâu?
Dữ liệu lưu trong cơ sở dữ liệu SQLite cục bộ trên máy tính. Dữ liệu tự động lưu ngay lập tức sau mỗi thay đổi — không cần nhấn nút "Lưu" thủ công.
❓ Một máy tính có thể dùng nhiều vai trò không?
Có. Nhấn "← Quay lại" hoặc "Đổi vai trò" để chuyển đổi tự do giữa Admin / HLV / Thư ký bất kỳ lúc nào mà không mất dữ liệu.
❓ Có thể bốc thăm lại không?
Có. Nhấn "🔄 Bốc thăm lại" — nhưng LƯU Ý: toàn bộ kết quả trận đấu cũ sẽ bị xóa. Hệ thống tự động tạo auto-backup trước khi xóa để bảo vệ dữ liệu.
❓ File .krt là gì? Tại sao cần file này?
File .krt là "thẻ mời" kỹ thuật số do Admin tạo ra. Nó chứa: thông tin giải đấu, danh sách nội dung thi đấu, và giới hạn thời gian nhập VĐV. HLV mở file này để biết thông tin và đăng ký VĐV đúng thời hạn.
❓ File .kmatch là gì?
File .kmatch là file chấm điểm chứa toàn bộ sơ đồ thi đấu sau khi bốc thăm xong. Admin tạo và gửi cho Thư ký. Thư ký mở file để bấm điểm từng trận trong thời gian được phép.
❓ HLV nhập VĐV sau deadline được không?
Không được. Hệ thống tự động khóa chức năng thêm/sửa/xóa VĐV khi hết thời hạn. Nếu cần thêm thời gian, HLV liên hệ Admin để tạo lại file .krt với deadline mới.
❓ BYE là gì?
BYE (lượt trống) xuất hiện khi số VĐV không phải lũy thừa của 2 (4, 8, 16, 32...). VĐV được BYE tự động thắng vòng 1 mà không cần thi đấu. Hệ thống phân bổ BYE đều 2 nửa bảng để công bằng.
❓ Hạt giống (Seed) là gì? Cách đặt?
Hạt giống là VĐV được xếp hạng từ trước (1-8), thường là VĐV mạnh. Khi thêm VĐV, điền số hạt giống vào ô "Hạt giống". Thuật toán bốc thăm đặt hạt giống vào vị trí cố định để các VĐV mạnh không gặp nhau ở vòng đầu.
❓ Cách gửi file giữa Admin và HLV/Thư ký?
• 💾 Copy qua USB — Nhanh, không cần internet
• 📧 Gửi qua Email — Tiện cho khoảng cách xa
• 💬 Gửi qua Zalo / Messenger — Phổ biến nhất ở Việt Nam
• ☁️ Upload lên Google Drive rồi chia sẻ link download
❓ Phần mềm hỗ trợ thi đấu đồng đội không?
Có. Khi tạo hạng mục đồng đội, hệ thống nhóm VĐV theo CLB thành các đội và bốc thăm theo đội. Bracket hiển thị tên CLB thay vì tên VĐV. Huy chương cũng được tính theo đội.
