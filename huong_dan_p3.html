CHƯƠNG 8. BACKUP & ĐỒNG BỘ DỮ LIỆU

Tính năng Backup giúp sao lưu toàn bộ dữ liệu giải đấu và đồng bộ giữa nhiều máy quản lý khác nhau. Đây là tính năng quan trọng khi có nhiều Admin cùng quản lý một giải.

8.1. Mở Quản lý Backup

1
Từ trang chủ Admin → Nhấn nút "💾 Backup" hoặc biểu tượng đám mây
2
Cửa sổ "Quản lý Backup" mở ra, hiển thị: Số giải đấu · Dung lượng dữ liệu · Số bản auto-backup

8.2. Xuất Backup — Sao lưu dữ liệu

1
Nhấn thẻ "📤 Xuất Backup"
2
Nhập ghi chú để dễ phân biệt sau — VD: "Backup sau khi import VĐV CLB Hà Nội"
3
Nhấn "💾 Xuất file Backup (.kbackup)"
4
Chọn vị trí lưu → File .kbackup chứa toàn bộ dữ liệu tất cả giải đấu

8.3. Nhập Backup — Khôi phục dữ liệu

1
Nhấn thẻ "📥 Nhập Backup"
2
Chọn file .kbackup từ Admin khác hoặc từ bản backup cũ của mình
3
Hệ thống hiển thị bảng so sánh chi tiết:
• Số giải đấu · Hạng mục · VĐV · Đã bốc thăm — của máy hiện tại vs file backup
• Danh sách giải: Mới trong backup / Khác biệt / Chỉ có ở máy này / Giống nhau
4
Chọn chế độ khôi phục:
• "🔀 Gộp dữ liệu" — Giữ cả 2, giải trùng ID giữ bản có nhiều dữ liệu hơn (AN TOÀN)
• "🔄 Thay thế" — Xóa hết dữ liệu hiện tại, thay bằng backup (dữ liệu cũ tự auto-backup trước)

8.4. Tạo Checkpoint thủ công

1
Nhấn thẻ "📌 Tạo Checkpoint"
2
Hệ thống lưu trạng thái hiện tại vào danh sách Auto-backup với nhãn "Checkpoint thủ công"
3
Có thể khôi phục checkpoint này sau từ mục "🕐 Lịch sử Backup"
💡 Khi nào nên tạo Checkpoint: Trước khi bốc thăm · Trước khi import dữ liệu lớn · Trước khi thực hiện thay đổi quan trọng

8.5. Xem lịch sử & Khôi phục Auto-backup

1
Nhấn thẻ "🕐 Lịch sử Backup"
2
Danh sách bản auto-backup hiển thị: thời gian tạo · lý do tạo · dung lượng
3
Nhấn "Khôi phục" ở bản muốn phục hồi → Xác nhận → Dữ liệu hiện tại được auto-backup rồi khôi phục
💡 Quy trình đồng bộ nhiều Admin:
1. Admin chính Xuất Backup → gửi file .kbackup cho Admin phụ (Zalo/USB/Drive)
2. Admin phụ Nhập Backup → chọn Gộp dữ liệu → tiếp tục làm việc
3. Khi xong, Admin phụ Xuất Backup lại → gửi về cho Admin chính để cập nhật

CHƯƠNG 10. CÂU HỎI THƯỜNG GẶP (FAQ)

❓ Phần mềm có cần internet không?
Không. Phần mềm hoạt động 100% offline. Chỉ cần internet khi: kích hoạt license lần đầu, gửi yêu cầu hỗ trợ qua phần mềm, hoặc cập nhật phiên bản mới.
❓ Dữ liệu được lưu ở đâu?
Dữ liệu lưu trong cơ sở dữ liệu SQLite cục bộ trên máy tính. Dữ liệu tự động lưu ngay lập tức sau mỗi thay đổi — không cần nhấn nút "Lưu" thủ công.
❓ Một máy tính có thể dùng nhiều vai trò không?
Có. Nhấn "← Quay lại" hoặc "Đổi vai trò" để chuyển đổi tự do giữa Admin / HLV / Thư ký bất kỳ lúc nào mà không mất dữ liệu.
❓ Có thể bốc thăm lại không?
Có. Nhấn "🔄 Bốc thăm lại" — nhưng LƯU Ý: toàn bộ kết quả trận đấu cũ sẽ bị xóa. Hệ thống tự động tạo auto-backup trước khi xóa để bảo vệ dữ liệu.
❓ File .krt là gì? Tại sao cần file này?
File .krt là "thẻ mời" kỹ thuật số do Admin tạo ra. Nó chứa: thông tin giải đấu, danh sách nội dung thi đấu, và giới hạn thời gian nhập VĐV. HLV mở file này để biết thông tin và đăng ký VĐV đúng thời hạn.
❓ File .kmatch là gì?
File .kmatch là file chấm điểm chứa toàn bộ sơ đồ thi đấu sau khi bốc thăm xong. Admin tạo và gửi cho Thư ký. Thư ký mở file để bấm điểm từng trận trong thời gian được phép.
❓ HLV nhập VĐV sau deadline được không?
Không được. Hệ thống tự động khóa chức năng thêm/sửa/xóa VĐV khi hết thời hạn. Nếu cần thêm thời gian, HLV liên hệ Admin để tạo lại file .krt với deadline mới.
❓ BYE là gì?
BYE (lượt trống) xuất hiện khi số VĐV không phải lũy thừa của 2 (4, 8, 16, 32...). VĐV được BYE tự động thắng vòng 1 mà không cần thi đấu. Hệ thống phân bổ BYE đều 2 nửa bảng để công bằng.
❓ Hạt giống (Seed) là gì? Cách đặt?
Hạt giống là VĐV được xếp hạng từ trước (1-8), thường là VĐV mạnh. Khi thêm VĐV, điền số hạt giống vào ô "Hạt giống". Thuật toán bốc thăm đặt hạt giống vào vị trí cố định để các VĐV mạnh không gặp nhau ở vòng đầu.
❓ Cách gửi file giữa Admin và HLV/Thư ký?
• 💾 Copy qua USB — Nhanh, không cần internet
• 📧 Gửi qua Email — Tiện cho khoảng cách xa
• 💬 Gửi qua Zalo / Messenger — Phổ biến nhất ở Việt Nam
• ☁️ Upload lên Google Drive rồi chia sẻ link download
❓ Phần mềm hỗ trợ thi đấu đồng đội không?
Có. Khi tạo hạng mục đồng đội, hệ thống nhóm VĐV theo CLB thành các đội và bốc thăm theo đội. Bracket hiển thị tên CLB thay vì tên VĐV. Huy chương cũng được tính theo đội.

CHƯƠNG 11. XỬ LÝ SỰ CỐ & LIÊN HỆ HỖ TRỢ

11.1. Các lỗi thường gặp và cách xử lý

🔴 Không mở được file .krt hoặc .kmatch
  • Kiểm tra file có bị lỗi không → Yêu cầu Admin gửi lại
  • Đảm bảo file đúng phần mở rộng: .krt hoặc .kmatch
  • Tránh đặt tên file có ký tự đặc biệt (dấu cách đầu, $ % # ...)
🔴 HLV không thêm được VĐV
  • Kiểm tra thanh trạng thái — phải hiển thị "Đang trong thời gian nhập"
  • Nếu hiện "Chưa đến thời gian" → Chờ đến ngày Admin quy định
  • Nếu hiện "Đã hết hạn" → Liên hệ Admin tạo lại file .krt với deadline mới
🔴 Không bốc thăm được
  • Cần ít nhất 2 VĐV trong hạng mục cá nhân
  • Hạng mục đồng đội cần ít nhất 2 CLB khác nhau
  • Kiểm tra VĐV không bị trùng dữ liệu
🔴 PDF xuất trống hoặc sai nội dung
  • Đảm bảo đã bốc thăm trước khi xuất PDF
  • Chọn máy in "Microsoft Print to PDF" hoặc tương đương
  • Khởi động lại phần mềm và thử lại
🔴 License hết hạn, mất tính năng
  • Mở Quản lý Bản quyền → Tab "Yêu cầu hỗ trợ"
  • Chọn "🔄 Gia hạn License" → Điền thông tin → Gửi yêu cầu
  • Hoặc liên hệ trực tiếp: 0336.440.523 (Zalo/Gọi)
🔴 Mất dữ liệu sau khi đóng phần mềm
  • Vào Quản lý Backup → Lịch sử Backup → Khôi phục bản auto-backup gần nhất
  • Thường xuyên Xuất Backup ra file .kbackup để lưu ngoài
  • Không dùng Task Manager để tắt phần mềm đột ngột
🔴 Kích hoạt license báo "Key không hợp lệ"
  • Kiểm tra ID Máy — phải giống với ID đã gửi cho nhà cung cấp khi đặt mua
  • Copy/paste key từ email/tin nhắn, tránh gõ tay
  • Liên hệ nhà cung cấp kèm ID Máy hiện tại để được cấp key đúng
🔴 Phần mềm đơ, treo, không phản hồi
  • Nhấn Alt+F4 để đóng rồi mở lại
  • Nếu vẫn bị treo: Dùng Task Manager (Ctrl+Shift+Esc) → End Task → Mở lại
  • Thử khởi động lại máy tính
  • Nếu lỗi lặp lại: Chụp màn hình lỗi → Liên hệ hỗ trợ kỹ thuật
