CHƯƠNG 2. CÀI ĐẶT & KHỞI ĐỘNG

2.1. Cài đặt phần mềm

1
Tải file cài đặt K-SPORT Setup x.x.x.exe từ nhà cung cấp
2
Nhấp đúp vào file .exe để chạy trình cài đặt
3
Chọn thư mục cài đặt (mặc định: C:\Program Files\K-SPORT)
4
Nhấn Install và chờ quá trình hoàn tất (khoảng 1-2 phút)
5
Nhấn Finish — Phần mềm tạo shortcut trên Desktop
💡 Lưu ý: Nếu Windows Defender cảnh báo "Unknown Publisher", chọn "More info" → "Run anyway". Đây là cảnh báo thông thường với phần mềm chưa được ký số bởi Microsoft.

2.2. Khởi động phần mềm

  • Nhấp đúp biểu tượng K-SPORT trên Desktop, hoặc vào Start Menu
  • Màn hình Splash/License hiển thị trong vài giây rồi tự chuyển sang màn hình chọn vai trò
  • Lần đầu cài đặt: Phần mềm tự kích hoạt chế độ Dùng thử (Trial) — đầy đủ tính năng trong thời hạn giới hạn
⚠️ Tắt phần mềm đúng cách: Nhấn X để đóng hoặc dùng Alt+F4. Không tắt đột ngột bằng Task Manager để tránh mất dữ liệu đang xử lý.

CHƯƠNG 3. KÍCH HOẠT & QUẢN LÝ LICENSE (BẢN QUYỀN)

License là bản quyền sử dụng phần mềm. Hệ thống có 2 loại:

Loại LicenseMô tảThời hạnHạn chế
🔓 Dùng thử (Trial)Tự động kích hoạt khi cài lần đầuGiới hạn ngàyWatermark trên PDF
✅ License chính thứcNhập key do nhà cung cấp cấpTheo gói muaKhông hạn chế

3.1. Xem thông tin License hiện tại

1
Từ màn hình Admin → Tìm biểu tượng 🛡️ (góc trên hoặc dưới màn hình)
2
Nhấn vào biểu tượng để mở cửa sổ "Quản lý Bản quyền"
3
Tab "Thông tin" hiển thị: Loại license · Tên tổ chức · Ngày kích hoạt · Ngày hết hạn · Số ngày còn lại (thanh màu)

3.2. Kích hoạt License — Nhập key mới

📋 Bước 1: Lấy ID Máy tính

1
Mở Quản lý Bản quyền → Tab "Thông tin"
2
Tìm mục "🖥️ ID Máy tính của bạn" — đây là mã định danh duy nhất của máy
3
Nhấn nút 📋 (Copy) — ID được sao chép vào clipboard
4
Gửi ID này kèm thông tin đặt hàng cho nhà cung cấp: 0336.440.523

🔑 Bước 2: Nhập License Key nhận được

1
Chuyển sang tab "Kích hoạt"
2
Dán (Ctrl+V) License Key vào ô nhập liệu
3
Nhấn nút "Kích hoạt"
4
Thông báo "🎉 Kích hoạt bản quyền thành công!" → Hoàn tất

📁 Hoặc: Kích hoạt bằng file .lic

1
Nhận file .lic từ nhà cung cấp qua email
2
Nhấn nút "📁 Mở file License (.lic)"
3
Chọn file .lic → Hệ thống tự động kích hoạt

3.3. Gia hạn License

⚠️ Cảnh báo hết hạn: Khi license còn < 7 ngày → thanh màu vàng. Khi còn < 3 ngày → màu đỏ. Khi hết hạn → một số tính năng bị hạn chế.

Cách 1: Gửi yêu cầu gia hạn qua phần mềm (cần có internet)

1
Mở Quản lý Bản quyền → Tab "Yêu cầu hỗ trợ"
2
Chọn loại yêu cầu: "🔄 Gia hạn License"
3
Điền thông tin liên hệ: số điện thoại hoặc email
4
Nhấn "📨 Gửi yêu cầu" — Nhà cung cấp sẽ liên hệ lại sớm nhất

Cách 2: Liên hệ trực tiếp nhà cung cấp

  • 📞 Điện thoại / Zalo: 0336.440.523 (Trương Lưu Quân)
  • 📧 Email: luuquankarate@gmail.com
  • Cung cấp: ID Máy tính + Tên tổ chức/CLB để được cấp key gia hạn

3.4. Đổi thiết bị / Reset máy

Khi bạn muốn chuyển license sang máy tính mới:

1
Trên máy cũ: Vào Quản lý Bản quyền → Tab "Thông tin" → Nhấn "Hủy kích hoạt license hiện tại"
2
Hoặc vào Tab "Yêu cầu hỗ trợ" → Chọn "🖥️ Reset máy (đổi thiết bị)" → Gửi yêu cầu
3
Cài phần mềm trên máy mới → Lấy ID máy mới → Gửi cho nhà cung cấp nhận key mới
4
Kích hoạt trên máy mới theo hướng dẫn mục 3.2

CHƯƠNG 4. MÀN HÌNH CHỌN VAI TRÒ

4.1. Giới thiệu 3 vai trò

Khi mở phần mềm, màn hình chọn vai trò hiển thị 3 thẻ lớn. Nhấn vào thẻ tương ứng với chức năng bạn cần:

ThẻVai tròNên chọn khi
👨‍💼 AdminBan tổ chứcBạn quản lý giải đấu, cần bốc thăm, in PDF, xem thống kê
🏆 Huấn luyện viênHLV đội/CLBBạn nhận file .krt từ Admin và cần nhập danh sách VĐV
🎯 Thư kýThư ký trận đấuBạn nhận file .kmatch từ Admin và cần bấm điểm các trận

4.2. Chuyển đổi vai trò

  • Nhấn nút "← Quay lại" hoặc "Đổi vai trò" từ bất kỳ màn hình nào để quay về màn hình chọn vai trò
  • Một máy tính có thể dùng luân phiên cả 3 vai trò — dữ liệu mỗi vai trò được lưu riêng biệt
💡 Gợi ý: Trong một buổi tổ chức giải, người vận hành máy tính chính thường dùng vai trò Admin. HLV và Thư ký dùng các máy tính riêng hoặc nhận/gửi file qua USB/Zalo.
